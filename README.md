# REST API Library Project

## Лабораторна робота №2: Розробка API з використанням фреймворка FastAPI.
### 


## Функціонал (CRUD)
Реалізовано наступні асинхронні операції для ресурсу `Book`:
1. **GET /books** — отримання повного списку книг.
2. **GET /books/{id}** — пошук книги за ідентифікатором.
3. **POST /books** — додавання нової книги до бібліотеки (з валідацією даних).
4. **PUT /books/{id}** — повне оновлення інформації про існуючу книгу.
5. **DELETE /books/{id}** — видалення книги зі списку.
